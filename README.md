# marcusmalloc/tap

Small macOS tools.

```sh
brew install --cask marcusmalloc/tap/baretab
brew install --cask marcusmalloc/tap/pomodoro-blocker
```

[BareTab](https://github.com/marcusmalloc/alt-tab-macos-but-free) switches windows.
[Pomodoro Blocker](https://github.com/marcusmalloc/pomodoro-blocker) runs focus timers and blocks distractions.

Casks update automatically when a release is published. Maintainers can also run **Update Pomodoro cask** in Actions to retry publication. It verifies the archive checksum before publishing. Run updater tests with `python3 -m unittest discover -s tests`.
